# vit_jax Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a runnable `vit_jax` Vision Transformer example for MNIST using `Flax + Optax + JIT + TrainState`, plus setup and comparison docs.

**Architecture:** The implementation lives under `vit_jax/` with clear boundaries between model definition, data loading, and training logic. The training loop uses explicit parameter/state handling, jitted train and eval steps, and lightweight tests that prove the new JAX code behaves as expected before full training is run.

**Tech Stack:** Python, JAX, Flax, Optax, NumPy, torchvision or an equivalent MNIST loader, pytest
